## 项目说明

本仓库是「南工职大昇腾计算精英班」20天自学作品集，内容覆盖 Linux 系统运维、Shell 脚本、Python 数据处理、Docker 容器化、AI 推理服务交付五大模块，共计 20 个实战案例。

每日打卡 = **项目案例 + 理论笔记**双交付，模拟昇腾 FAE / 模型部署调优工程师真实工作流：环境部署 → 数据处理 → 容器化 → 推理服务交付。
