# Day 8 理论笔记：Python 数据类型 / 结构 / 控制流

## 1. 基础类型与类型转换

**概念**：`int`（整数）、`float`（浮点数）、`str`（字符串）、`bool`（True/False）、`None`（空值）。类型转换用 `int()`、`float()`、`str()`、`bool()`。f-string（`f"{变量}"`）是格式化输出的现代写法，支持 `:04d`（补零）、`:.2f`（保留小数）等格式符。

**为什么重要**：数据预处理的核心就是从文件、字符串里"抠"出正确的数值类型。比如文件名 `cat_001.jpg` 里的 `001` 是字符串，要转成 `int` 才能参与排序和计数。类型错了，后面的计算全错。

**踩坑**：`"001"` 用 `int()` 转成的是 `1`，不是 `001`——前导零会丢。要保持格式必须用 f-string 的补零符 `:04d`。字符串和数字不能直接相加，必须先转换。

---

## 2. 数据结构：list / tuple / dict / set

**概念**：`list` 有序、可修改；`tuple` 有序、不可修改；`dict` 键值对，键唯一；`set` 无序、元素不重复。列表推导式 `[表达式 for x in 可迭代对象]` 一行生成列表；字典推导式 `{键:值 for ...}` 一行生成字典。切片 `lst[start:end:step]` 取子序列。

**为什么重要**：AI 数据处理的四大金刚——list 存一批数据、dict 做类别→索引映射、tuple 表示固定配对（图片,标签）、set 去重。列表/字典推导式让代码从 5 行变 1 行，是 Python 最优雅的表达。

**踩坑**：dict 的键必须不可变（可用 str/int/tuple，不能用 list 作键）。切片是左闭右开——`lst[0:3]` 取的是下标 0、1、2，不包含 3。列表推导式里不要塞过于复杂的逻辑，否则可读性差。

---

## 3. 控制流：if / for / while / enumerate / zip

**概念**：`if/elif/else` 条件分支。`for x in 可迭代对象` 遍历（Python 的 for 和 C 语言不同，是"for-each"式）。`while 条件` 循环直到条件不成立。`enumerate(列表)` 同时取下标和值，`zip(a, b)` 并行配对两个序列，`break` 跳出循环，`continue` 跳过本次，`pass` 占位。

**为什么重要**：批量处理 N 张图片、N 条日志，靠的就是循环；根据不同条件走不同逻辑，靠的就是判断。`enumerate` 是"需要序号"时的标准写法，`zip` 是把图片路径和标签一一配对的神器。

**踩坑**：`while` 忘记更新循环变量会死循环。`for` 循环里修改正在遍历的列表会产生意想不到的结果，应该遍历副本 `for x in lst[:]`。`if x:` 判断中空字符串、0、空列表、None 都被当作 False，容易踩坑。

---

## 4. 为什么 Python 是 AI 首选语言

**概念**：Python 的优势不在运行速度，而在**生态**——NumPy（数组计算）、PyTorch（深度学习框架）、Pandas（表格数据）、OpenCV（图像处理）等海量库构成了完整的 AI 工具链。Python 语法简洁，胶水特性强，底层计算交给 C/CUDA，Python 负责调度。

**为什么重要**：昇腾的 MindSpore、CANN 工具链都提供 Python 接口。做模型部署、数据预处理、推理调用，你写的都是 Python。学会 Python 就是拿到了 AI 生态的通行证。

**踩坑**：Python 动态类型灵活但也是坑——运行时才报错，不像 Java/C 编译期就拦下。工程中要靠类型注解（Type Hints）和 Pydantic 补上这层保障。
